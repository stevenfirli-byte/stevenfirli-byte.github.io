# Steven Firli Sitorus — Website akademik

Hosting gratis melalui GitHub Pages.

## Menambahkan PDF

Upload PDF sesuai lokasi link pada HTML, misalnya:
- `documents/aps/robustness-analysis.pdf`
- `documents/aps/use-case.pdf`
- `documents/asd/avl-tree.pdf`
- `documents/bgp-routing.pdf`

Nama file dan huruf besar-kecil harus cocok. Semua file PDF yang tertaut saat ini adalah contoh dan **belum disertakan**. Jika PDF belum diunggah, link akan menghasilkan 404.

## Publikasi

Unggah isi folder ini (bukan folder pembungkusnya) ke root repository `stevenfirli-byte.github.io`. Di Settings > Pages, pilih Deploy from a branch > main > /(root).
